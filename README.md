# mini-rag


This is a trial project for mini-rag for a chatbot for the university of Texas A&M San Antonio  

## Requirements 

Python = 3.9 or later

#### Install python using mini-conda

 1) Download and install mini-conda 

 2) create a new env using this command:
 ```bash
 $ conda create -n mini-rag python
 ```
  
  ## Installation 

  ### Install the required packages

```bash
$ pip install -r requirements.txt
```

### Set up the enviornment variables

```bash
$ cp .env.example .env
```

#### Add your open_ai key in the enviornment file
